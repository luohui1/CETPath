# 英语之道：竞品分析与功能规划（草案）

> 调研日期：2026-11-01。调研对象：英语真题在线（zhenti.burningvocabulary.cn，使用已登录的专业版账号）、扇贝单词这类背词产品。

## 1. 合规红线（先读）

英语真题在线的帮助页里有一份《声明》，**明确禁止**：

- 克隆、仿制或变形其界面、题库和技术服务
- 批量抓取、下载、二次分发其题库和资源（PDF、图片、音视频）
- 以其内容为基础开发竞争性产品

声明里还说，其页面和资源中嵌入了不可见的数字水印。

所以英语之道的边界是：

| 可以做 | 不能做 |
| --- | --- |
| 借鉴通用功能类型（查词、生词本、按年份的真题目录、听力分段播放），这些是行业通用做法 | 抓取或下载对方的 PDF、音频、解析、题路精讲 |
| 自己设计界面和交互（我们本来就要更现代的风格） | 模仿对方的界面布局和视觉 |
| 真题内容由我们自己整理、录入（来源要合法） | 把对方的试卷文件改一改再用 |
| 词典用开源数据（如 ECDICT，MIT 协议） | 直接调用对方的查词接口 |

另外，考研和四六级真题本身的版权属于命题机构。内部学习使用问题不大；如果以后要商业化公开分发，需要另外确认授权。

## 2. 英语真题在线：功能拆解

### 2.1 信息结构

- **首页**：考试分类入口（考研、四级、六级、专四专八）
- **真题目录**（以考研为例）：2000–2026 年共 44 套，2010 年起分英语一、英语二；可快速定位年份；有考试倒计时
- **学习中心**：最近学习（试卷名、几小时前、生词数、查了几个解析、几页笔记、"继续"按钮）
- **个人中心**：账号（邮箱登录）、会员有效期、续期、邀请好友延长会员

### 2.2 试卷页（核心）

试卷页本质是一个 **PDF 阅读器**（基于 PDF.js），外加：

- 阅读：缩放、单页/双页/书籍视图、缩略图、大纲、查找、下载、打印、颜色模式跟随系统
- 查词：点击 PDF 里的单词查释义和读音，可显示"查词标记"，可关闭单词声音；支持句子翻译
- 标注：4 色高亮、下划线、添加文本、笔写、手指书写、橡皮擦、撤销（专业版云同步）
- 听力：底部播放器，时间轴按题目分段（Conv 1 / Pass 1 / Record 1…），可跳到具体题号，倍速，听力原文
- 答题：在题号上标记答案；"解析答案"入口
- 生词本：页面左侧悬浮入口，专业版可导出中英 PDF

### 2.3 付费权益（专业版）

查单词和词组、单词读音；生词本导出中英 PDF；题号标记答案；句子翻译；手写标注高亮（云同步）；题路精讲（类似老师讲题的视频）；考研答案解析。

### 2.4 能看出来的问题

- **试卷是 PDF**：手机上要缩放拖动，阅读体验差；题目、选项、原文不是结构化数据，做不了自动判分、错题本、按题型练习
- **生词本只是个列表**：查过的词存下来就结束了，没有复习机制，记不住
- **账号和数据不稳**：常见问题里有"登录失效，单词丢失""为什么没有收到邮件""试卷显示不出来"
- **界面老旧**：传统网页风格，没有学习数据、打卡、进度这类激励

## 3. 扇贝单词这类产品：值得借鉴的做法

- **词书 + 每日计划**：选一本词书（四级、六级、考研），设定每天新词数，系统自动安排复习
- **背词流程**：看词 → 自评（认识 / 模糊 / 不认识）→ 详情（释义、例句、发音、词根词缀、助记）→ 按遗忘曲线安排下次复习
- **多种复习模式**：认读、拼写、听写
- **激励**：打卡日历、连续天数、学习统计
- **阅读里查词**：文章中点词查词，一键加入生词本，词和出处语境绑在一起

## 4. 英语之道：定位和差异化

一句话：**把"真题"和"背单词"打通**。在真题里遇到的生词，带着真题原句进入记忆系统；背单词时看到的例句，就是你做过的真题。

| 方向 | 英语真题在线 | 英语之道 |
| --- | --- | --- |
| 试卷形态 | PDF | 结构化试卷（题目、选项、原文、解析都是数据），手机自适应排版；保留 PDF 原卷作为对照 |
| 作答 | 在题号上手动标记 | 在线作答、自动判分、错题本、按题型练习 |
| 生词本 | 列表 + 导出 PDF | 生词本直接进入记忆复习（FSRS 算法），每个词带真题出处原句 |
| 词书 | 无 | 按考试大纲（四级、六级、考研）+ 真题词频生成词书 |
| 激励 | 无 | 每日计划、打卡、学习统计、复习预测 |
| 数据 | 登录失效会丢词 | 账号云同步 + 本地缓存，离线可用 |
| 风格 | 传统网页 | 现代、移动优先、深色模式、可安装（PWA） |

## 5. 功能地图（按优先级）

### P0：首版必做

1. **账号**：注册登录，数据云同步
2. **真题库**：考试分类 → 年份目录 → 试卷；"最近学习"和"继续"
3. **交互式试卷阅读器**：结构化排版，点词查词（含词形还原，如 *studies → study*），一键加入生词本（自动记下出处句子）
4. **在线作答**：选择题作答、交卷判分、查看答案和解析
5. **生词本**：列表、搜索、按出处筛选、导出（CSV / PDF）
6. **背单词**：FSRS 复习调度，自评三档，单词卡（释义、音标、发音、真题例句）

### P1：第二批

7. 听力播放器：按题分段、倍速、原文同步高亮
8. 词书 + 每日计划 + 打卡和统计
9. 错题本、按题型练习（阅读、完形、翻译…）
10. 拼写和听写复习模式
11. 笔记和高亮

### P2：以后再说

12. 句子翻译、长难句分析（可接入大模型）
13. 作文和翻译 AI 批改
14. 内容录入后台（把 PDF 或 Word 真题转成结构化数据）
15. 桌面或手机 App 打包

## 6. 技术方案（建议，待确认）

- **前端**：Next.js（React）+ TypeScript + Tailwind CSS + shadcn/ui，移动优先，支持 PWA 安装
- **后端**：Next.js 服务端接口 + PostgreSQL（开发阶段可先用 SQLite）+ Prisma
- **词典**：ECDICT（开源，MIT 协议，约 77 万词条，带四级、六级、考研等考试标签、词频和词形变化），导入自己的数据库
- **记忆算法**：ts-fsrs（开源 FSRS 算法，MIT 协议）
- **发音**：先用浏览器自带语音合成，后续可换成自建 TTS
- **试卷数据格式**：每套试卷一个 JSON（分部分、分题目，含原文、选项、答案、解析、听力分段时间点），配一个录入和校验工具
