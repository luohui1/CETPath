# 设计任务：D 轮——卷面阅读体验 与 E 轮——背单词

> 写给实施者的任务书。2026-11-03。视觉按 `设计任务-A轮-现代化.md`；在 A、B 轮之后开工（改同一批做题页文件）。

## D. 卷面阅读体验（做题页）

### D1. 页面缩略图栏

- 做题页左侧可收起的窄栏（宽 112px，平板竖屏默认收起），每页一张缩略图（pdf.js 按 0.15 倍渲染一次，缓存在内存；用现有的 `queueRender` 排队，不抢正文渲染）
- 当前页高亮（品牌蓝描边），点了跳页；缩略图上叠小字页码；有笔记的页右上角一个小点
- 快捷键 `T` 开关

### D2. 卷面查找

- `Ctrl/⌘+F` 弹出查找条（做题页顶部，不是浏览器的）；输入即搜 `words.json`（全卷单词，不区分大小写，支持词组：相邻词拼接）
- 命中的词在 `WordLayer` 上用荧光黄底高亮，当前命中深一级；`Enter`/`Shift+Enter` 上下一个，自动滚到并闪一下
- 显示"3 / 17"；`Esc` 关闭并清除

### D3. 手写笔改进

- **按住拉直**：荧光笔或笔画完后停住 300ms 不抬笔，笔迹变成两点间的直线（荧光笔变成等宽色带）；松手前再动又变回自由笔迹
- **笔预设**：工具栏上 3 个预设槽（颜色 + 粗细），长按当前预设保存；记在 settings
- **套索**：选中一片笔迹后可以整体拖动或删除（`InkLayer` 里按包围盒命中，`marks` 表更新坐标）

### D4. 导出带笔记的 PDF

- 工具栏"更多"里加"导出 PDF"；用 `pdf-lib` 在原 PDF 上画：手写笔迹和荧光（转成矢量路径，荧光用 multiply 混合）、下划线、便签（画成页边的小黄块 + 文字），可选"附答题情况"（最后一页加一张答题卡：题号、我的答案、正确答案）
- 文件名 `2024年12月四级第2套-笔记.pdf`；导出进度条；平板上用 `navigator.share` 分享，桌面直接下载

### D5. 做题页小修

- 双页视图（横屏且页宽 < 一半屏宽时可选）
- 页码跳转输入框
- 便签支持拖动位置

文件：`ExamRoom.tsx`（栏、查找条、工具栏）、`PaperPages.tsx`（高亮命中、缩略图渲染）、`InkLayer.tsx`（拉直、套索）、`src/lib/marks.ts`、新 `src/lib/exportPdf.ts`、`src/exam/ThumbRail.tsx`、`src/exam/FindBar.tsx`。**不要动** `ExamPage` 的主渲染逻辑和听力逻辑。

## E. 背单词

### E1. 复习模式

开始页加模式选择（记在 settings）：
- **认读**（现有）：看英文 → 自评
- **拼写**：显示中文释义 + 音标 + 发音，输入英文；逐字母核对（对的字母墨色、错的红色），错 2 次显示首字母提示，错 3 次显示全词并算"不认识"
- **听写**：自动播放真人发音（`speak()`），输入英文；其余同拼写
- 模式只影响"怎么考"，评分进 FSRS 的逻辑不变（`src/lib/learning.ts` 的 `grade` 映射：拼写全对 = 认识，一次提示 = 模糊，看答案 = 不认识）

### E2. 单词卡加真题上下文

- 卡片背面除了释义，列出这个词在做过的试卷里出现的原句（`vocab.sources` 已有）和你在卷面上对它做的批注（`marks` 表里 `wordRange` 覆盖这个词的高亮/下划线/便签，按词查）
- 每条可以点"在卷面上看"跳过去

### E3. 词书页

- 每本书显示"已学 / 总数"的答题卡式进度，和"按词频"的分段（前 1000、1000–3000……各学了多少）
- 可以把一本书里某个词频段设为"本周重点"（settings），每日新词优先从这段里出

文件：`src/pages/Review.tsx`、`src/pages/Books.tsx`、`src/lib/learning.ts`、`src/lib/settings.ts`、新 `src/review/SpellCard.tsx`。
