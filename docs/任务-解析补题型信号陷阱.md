# 任务：给四六级每道选择题的解析补"题型 / 一句话结论 / 做题信号 / 错项陷阱"

> 直接把这份文件整篇发给执行的 Agent。仓库：luohui1/CETPath。需要本地有 `public/papers/`（试卷数据，不在 git 里）。

## 目标
`public/papers/explain/<试卷id>.json` 里每道选择题已经有结构化解析 `fields`（定位句、思路、逐项错因、生词、译文）。
这次给四六级（`cet4-*`、`cet6-*`）每道**选择题**的 `fields` 补 4 个字段，界面已经支持显示：

| 字段 | 要求 | 例子 |
|---|---|---|
| `kind` | 题型，见下面各部分的可选值 | `细节` |
| `brief` | 一句话结论，≤ 48 字，**开头写"选X："**，说人话 | `选B：原文说减税缺乏明显竞争对手，即无替代方案。` |
| `signal` | 做这题该盯的信号，≤ 64 字（最好 ≤ 40） | `题干 remain popular → 定位第二段 lacks rivals` |
| `traps` | 错误选项字母 → 陷阱名（只写错误选项） | `{"A": "答非所问", "C": "范围扩大", "D": "无中生有"}` |

陷阱名只能用：偷换对象、程度篡改、无中生有、常识绑架、因果颠倒、范围扩大、张冠李戴、正反颠倒、原词照搬、答非所问、词性不符、语义不符。
写作、翻译不用补。答案以输入里的"键="为准，不要改答案；依据原文和现有解析，不编造。

## 各部分怎么写
- **听力（1–25）**：`kind` 从 主旨 / 细节 / 原因 / 观点态度 / 建议 / 推断 选。`signal` 写出题位：开头主旨句、转折（but / however / actually）、因果、强调、最高级、建议之后；四级多原词复现，六级多同义替换。常见陷阱：原词照搬、张冠李戴（说话人或时间对不上）、常识绑架、无中生有。
- **选词填空（26–35）**：`kind` 写这个空要的词性和形式，如 `名词复数`、`动词过去式`、`形容词`、`副词`。`signal` 写语法槽位线索，如 `a ___ stretch of land → 填形容词修饰 land`。`traps` 只写 1–2 个最迷惑的候选，常用 词性不符、语义不符；没有就写 `{}`。
- **长篇阅读 / 段落匹配（36–45）**：`kind` 一律 `段落匹配`。`signal` 写定位词：一个好找的（专有名词、数字、大写词）+ 一个核心意思词；全文反复出现的主题词不能当定位词。`traps` 一般写 `{}`；原词重合多却不是答案的段落可以写 `原词照搬`。
- **仔细阅读（46–55）**：`kind` 从 细节 / 推理 / 主旨 / 态度 / 词义 / 例证 选。方法：先题干定位，再拿定位句和选项做同义替换比对；推理题也只是原文的同义改写，不多推一步；例子本身不是答案，答案是紧挨着的论点句；熟词常义多半是错的。三个错误选项都要写陷阱，按**这个选项实际错在哪**选名字（和现有解析的逐项错因对得上），别都写"无中生有"。

## 每套卷子的流程
```bash
pip install pymupdf    # 第一次
python3 scripts/enrich_explanations.py status            # 看哪些卷子还差多少题
python3 scripts/structure_explanations.py prep <试卷id> --all --full   # 注意不要加 python -I
# 读 data/cache/structure/inputs/<试卷id>.txt（原文、选项、答案键、现有解析）
# 写批次文件 data/cache/structure/enrich/<试卷id>.json：
#   {"q1": {"kind": "...", "brief": "...", "signal": "...", "traps": {...}}, ..., "q55": {...}}
python3 scripts/enrich_explanations.py merge <试卷id> data/cache/structure/enrich/<试卷id>.json
# 有"未通过"的按提示改批次文件，再 merge 一次（重复 merge 没关系）
```
一次做一套，做完一套 merge 一套。全部做完后 `status` 应该显示"还差 0 题"（少数没有结构化解析的题会跳过，没关系）。
