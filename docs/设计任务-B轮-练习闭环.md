# 设计任务：B 轮——练习闭环（错题本、交卷报告、练习模式）

> 写给实施者的任务书。2026-11-03。视觉按 `设计任务-A轮-现代化.md` 的「考场与文具」做；A 轮做完后再开工（两轮改同一批文件）。

## 0. 目标

做题 → 交卷 → 看报告 → 错题进本 → 重做错题 → 做对两次自动清掉。这是一个学习产品真正的闭环，现在只有前两步。

## B0. 做题页小功能（2026-11-03 用户追加，和下面一起做）

用户原话："答题的时候可以工具栏加一个计时器（手动的，可以计时我这个题花了多久）；那个总计时器是全真模拟的时候才有，其他情况下不要有了；题目旁边可以标用时；答题卡简单一点就行。"

### B0.1 两种做题方式

开始一套整卷时选（记在 settings 里作为默认，开始页可改）：
- **全真模拟**：按考试时长**总倒计时**（现有 `ExamTimer`），剩 10/5 分钟提醒，超时标红；交卷前看不到解析；`attempt.mode = "exam"`
- **普通做题**（默认）：**没有总计时器**；工具栏有单题秒表（B0.2）；随时交卷；`attempt.mode = "free"`

专项训练、重做错题、练习模式一律没有总计时器（去掉现在专项的正计时显示）。总用时仍然在后台累计进 `spentSec`（交卷单要用），只是不显示。

### B0.2 单题秒表（工具栏）

- 工具栏右侧一个秒表（`IconStopwatch` + `mm:ss`），默认停着
- **自动模式**（默认开）：点开任何一道题的选项框或开始写作答框时，秒表自动从 0 开始计这道题；选定答案或切到别的题时把时间记到 `attempt.questionSec[qid]`（累加，同一题回头再看会继续加），秒表归零等下一题
- **手动**：点秒表 = 暂停/继续（比如中途被打断）；长按 = 归零当前题；设置里可以关掉自动模式，只手动
- 秒表显示用衬线数字、墨色；超过这类题的建议时长（听力每题 1 分钟、阅读每题 2 分钟、选词每题 1 分钟、长篇每题 1.5 分钟、翻译 15 分钟、作文 30 分钟）变红
- 当前在计哪道题：秒表左边显示"第 12 题"，点它跳到那道题

### B0.3 题目旁边标用时

- 卷面上：有记录用时的题，题号标记右下角一行 11px 灰色 `1:20`（这是全页唯一允许的 11px 小字）；超过建议时长的红色
- 答题卡上：格子里题号下面同样一行小字；没有记录就不显示
- 交卷单上：新增"最慢的 5 题"一行，和各部分的平均每题用时

### B0.4 答题卡：简单

**推翻 A 轮 4.5 里"机读答题卡（装订孔 + 每题一行 ABCD 泡）"的做法。** 用户要简单：
- 一张纸，顶部：已答 N/M（或交卷后的分数）+ 筛选（全部/未答/标记/错题）
- 下面按部分分组：部分名一行小标题，然后是**题号网格**（每行 6–8 格，格子 36px，圆角 6px），格子只显示题号；状态只靠底色：未答 白、已答 浅蓝、标记 右上角一个小点、交卷后 对 浅蓝/错 浅红/未答 灰
- 格子下面可选一行用时小字（B0.3）
- 没有装订孔、没有 ABCD 泡行、没有进度条、没有说明文字
- 底部：交卷 / 看解析 / 重做 按钮（现有）

## 2. 数据

不改试卷数据，只改本地库 `src/lib/db.ts`（升到 version 3）：

```ts
// 作答记录新增两个可选字段（旧记录没有就当默认）
interface AttemptRow {
  ...
  mode?: "exam" | "practice" | "retry";     // 整套/专项默认 exam
  sectionSec?: Record<string, number>;      // 每个部分花的秒数（按当前滚动到的部分累计）
}

// 新表：错题掌握情况，一题一行
interface MasteryRow {
  id: string;            // `${paperId}#${questionId}`
  paperId: string;
  questionId: string;
  kind: SectionKind;
  firstWrongAt: number;
  history: { at: number; right: boolean; mode: AttemptRow["mode"] }[];  // 每次作答，含最初那次
  retiredAt?: number;    // 连续做对两次后自动移出的时间；手动恢复就删掉
  note?: string;
}
db.version(3).stores({ mastery: "id, paperId, kind, firstWrongAt, retiredAt" });
```

规则（放在 `src/lib/mistakes.ts`）：
- 交卷（exam 或 practice）时，每道选择题：答错 → 没有行就建一行，有行就追加 history；答对且已有行 → 追加 history
- 重做（retry）时只追加 history；history 末尾连续两次 `right` → 设 `retiredAt`
- "待重做"= 有行且没 `retiredAt`；"已掌握"= 有 `retiredAt`
- 未答的题不进错题本（报告里单独列"未答"）
- 从旧数据迁移：第一次打开错题本时，把所有已交卷记录跑一遍上面的规则（`backfillMastery()`），只跑一次（settings 里记个标记）

## 3. 交卷单（`src/exam/ReportSheet.tsx`）

交卷确认后立刻出现，是一张"纸"（顶部红线、衬线大数字），盖一枚红章写分数（≥60% 蓝章"通过"，<60% 红章"再练"）。

```
┌─ 交卷单 ──────────────────────────────┐
│  2024年12月 四级 第2套          用时 1:48:20 │
│  [大数字] 41 / 55     74%   ▲ 比上次 +6%   │
│  ─────────────────────────────────────    │
│  听力      18/25  72%   38 分钟   ████░    │
│  选词填空   7/10  70%    9 分钟   ███░░    │
│  长篇阅读   9/10  90%   11 分钟   █████    │
│  仔细阅读   7/10  70%   27 分钟   ███░░    │
│  最弱：听力 · 比你的平均低 8%              │
│  ─────────────────────────────────────    │
│  错题 14 道 · 未答 3 道   [全部已加入错题本] │
│  q3 B→A  q7 C→D  q12 …（点击展开解析）       │
│                                            │
│  [看解析]  [重做错题 (14)]  [返回真题]        │
└────────────────────────────────────────┘
```

- "比上次"：同一考试（exam）上一次交卷的整套记录；没有就不显示
- "你的平均"：该考试、该题型所有交卷记录的平均正确率（`useKindStats` 已有）
- 各部分用时来自 `sectionSec`；没有（旧记录）就不显示用时列
- 写作、翻译只显示"已写 N 词"，不计分
- 关闭后可以从答题卡面板顶部"交卷单"按钮再打开

## 4. 错题本页（`src/pages/Mistakes.tsx`，路由 `/mistakes`）

主导航第 4 项（在"专项训练"之后），图标用 `IconStamp` 换成红色描边的"错"章；徽标 = 待重做数。

版面：
- 顶部概况（一张纸）：待重做 N · 本周新增 N · 已掌握 N；右侧按题型的小条（每种题型待重做几道）
- 筛选行：题型（胶囊）、试卷（下拉）、状态（待重做/已掌握/全部）
- 列表按**试卷**分组（一张卷子一张纸，左侧缩略图），组内每题一行：
  `[题号] 我的答案 ✗ → 正确答案   题干前 40 字（有 stem 的题）   [看解析 ▾] [卷面] [已掌握]`
  展开后显示 `Explanation` 组件
- 每组右上角"重做这套的错题 (N)"；页面右上角"重做全部待重做 (N)"（最多一次 30 题，超过按题型/试卷分批提示）
- 空状态：一张空的答题卡 + "交过卷的错题会自动收进来"

## 5. 重做（retry）

- 入口：交卷单、错题本页、错题本分组
- 路由：`/paper/:id/retry?q=q3,q7,q12`（整套）或沿用 `section` 参数 + `q`
- 行为：打开原卷做题页，`scope` 只包含这些题——卷面上其他题号标记隐藏、答题卡只列这些题、计时正计时、页面自动滚到第一道
- 作答记录：key = `${paperId}#retry`（每次重做覆盖，不保留历史；历史在 mastery 里）
- 交卷：出交卷单（只有这几题），写入 mastery；连续两次对的题提示"已掌握 N 道，移出错题本"
- 做题页顶部状态条显示"重做错题 · 第 2 次"（次数 = 该题 history 里 retry 的次数 + 1）

## 6. 练习模式（专项训练）

- 专项训练列表行和"来一篇"旁加模式选择（记在 settings：`practiceMode: "exam" | "practice"`，默认 exam）
- 练习模式下（`attempt.mode = "practice"`）：
  - `ChoicePanel` 选完一个选项立刻显示对错（正确描蓝、选错描红并标出正确项）+ 解析；该题锁定（不能改）
  - 状态条实时显示"答对 7 / 已答 9"
  - 计时正计时，不倒计时
  - 答题卡上答对蓝、答错红，实时更新
  - "交卷"改叫"结束练习"，出交卷单；中途离开再回来接着做
- 整套模考不提供练习模式（保持考场感）
