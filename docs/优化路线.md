## 2. 视觉方向：「考场与文具」

前两版（多邻国风、多邻国 + 像素融合）都被否了，问题不在细节：几种视觉语言叠在一起（糖果色立体按钮、像素字体、企业设计系统的控件），而且界面里没有任何东西像"试卷"——可这个产品的核心就是一张张真实的试卷。

现在的方向：界面像一张收拾整齐的书桌。

| 元素 | 做法 |
| --- | --- |
| 桌面 | 纸色背景（#f5f2eb），隐约一层方格本的点 |
| 纸张 | 白色卡片，一圈细线，10px 圆角，落在桌面上的一点阴影；不再有"厚度"按钮 |
| 墨 | 文字墨色（#1c2330）；品牌蓝 #1677ff 只做"动作"色（按钮、链接、当前项） |
| 红笔 | 只用来"批改"：错题、低正确率、倒计时数字、红章、侧边栏的待复习数 |
| 荧光笔 | 黄色只用来标记（高亮、星标） |
| 数字 | 衬线体（试卷上印的那种），`.num`；界面文字用系统无衬线 |
| 进度 | 答题卡式的小椭圆（`Bubbles`），做了的涂黑 |
| 完成 | 盖红章（`Stamp`）：做完的卷子、备考阶段 |
| 试卷 | 原卷第一页的缩略图（`PaperThumb`，`npm run thumbs` 生成）当封面 |
| 图标 | 只用 lucide 线性图标，一种线宽 |
| 动效 | 切页轻轻一推；不要浮动、弹跳 |

不要：糖果色、3D 立体按钮、像素字体和像素图标、关卡式的"真题之路"、表情符号。

代码：令牌和基础类在 `src/theme.css`；小件在 `src/components/paper-ui.tsx`；图标在 `src/components/PixelIcon.tsx`（名字沿用，实现已换成 lucide）。

## 4. 接下来分轮做（每轮做完都能用）

### 第 A 轮：把「考场与文具」铺到每一页（进行中）

1. 首页、真题训练、专项训练、侧边栏、倒计时牌 —— 已改
2. 背单词、生词本、词书、统计、设置：按同一套令牌过一遍（去掉彩色、改数字字体、改进度为小椭圆）
3. 做题页：工具栏、答题卡、听力条、解析面板对齐新令牌；答题卡本身就该长得像答题卡
4. 在 820×1180、1180×820、1366×1024 下逐页检查

### 第 B 轮：练得更有效（UWorld、粉笔的做法）

1. **错题本**：所有试卷、所有专项里做错的题集中在一起，按题型、试卷筛选；可以"只重做错题"，做对两次后自动移出
2. **交卷报告**：各部分用时、正确率，和上次、和平均比较；一键把本卷错题加进错题本
3. **练习模式**：专项训练可以选"做一题看一题"，选完马上显示对错和解析

### 第 C 轮：数据补全

1. 约 35 套只差 1–4 个答案的四六级卷：修答案抽取后导入
2. 听力逐字稿：把解析 PDF 里的听力原文识别出来，按句对齐到录音的分句上（现在只有时间没有文字）
3. 考研真题：用户自己找到后用 `import:kaoyan` 导入
4. 人工抽查答案键（现在只有机器校验）

### 第 D 轮：卷面阅读体验（英语真题在线、GoodNotes 的做法）
