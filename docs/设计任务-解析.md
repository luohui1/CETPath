# 设计任务：把题目解析做好

> 2026-11-03。用户原话："能不能把题目解析做好呢。" 数据部分在 C 轮之后做（同一批文件），界面部分并入 B 轮。

## 0. 现状和问题

解析层 `public/papers/explain/<id>.json` 里每题一段自由文本（官方解析整理 1885 条、AI 补写 518 条），带【定位】【详解】这类小标签，面板里按题堆着显示。问题：

1. 格式不统一：有的一句话，有的一长串；【定位】【详解】【语法判断】各套各样
2. "定位"只是一句话，**在卷面上看不到那句话在哪**；听力题引用了原文，**听不到那一句**
3. 没有"为什么其他选项错"（逐项分析），长篇阅读的同义替换是一段散文，不是对照表
4. 没有生词，看解析时遇到的词还得自己查
5. OCR 带来的错字（"填人"、粘词）
6. 面板密度高，一题的解析一大块灰字，读着累

## 1. 目标体验

解析面板里一题的样子（默认只看错题和未答的）：

```
┌ 12   你选 B · 答案 C                              [卷面] ┐
│ 定位  第二段第三句                                      │
│       "Praise can become an expectation, …"             │
│       [在卷面上标出]      （听力题：[▶ 听这一句]）         │
│ 思路  题干问"表扬为什么会适得其反"。原文说表扬会变成一种    │
│       期望，什么都得夸。所以选 C。                        │
│ ▸ 逐项  A 原文未提 · B 偷换概念 · D 与原文相反            │
│ ▸ 生词  expectation 期望 · rewarded 奖赏      [+ 生词本]  │
│ ⌜AI 解析⌝（只有 AI 补写的题有这枚蓝章）        [解析有问题] │
└─────────────────────────────────────────────────────────┘
```

- 默认展开 **定位、思路**；**逐项、生词** 折叠（遵守密度规则：一题三行能读完）
- **在卷面上标出**：卷面滚到定位句，句子上临时蓝色高亮 3 秒（复用 `InkLayer` 的词范围高亮，不写进 `marks`）；平板浮动面板时面板半透明让位
- **听这一句**：听力题调 `ListeningBar` 的 `playLine(index)`（需要 C 轮对齐出来的逐字稿行号）
- **长篇阅读**：定位下面是一张两列对照表（题干关键词 ↔ 原文表达）
- **选词填空、完形**：思路分成"语法"（词性和形式）和"语义"两行；生词里列候选词释义
- **翻译、写作**：参考范文 + 三条"要点" + "亮点表达"（短语和它的中文），没有逐项
- **解析有问题**：点一下记到本地（`settings` 里一个 `badExplanations` 列表），以后汇总重写

## 2. 数据：解析层加结构化字段

每题在原有 `text`、`by` 之外加 `fields`（旧的 `text` 保留做回退）：

```jsonc
{
  "text": "……",
  "by": "official",
  "fields": {
    "answer": "C",
    "locate": {
      "where": "第二段第三句",
      "quote": "Praise can become an expectation",
      "page": 3,                // 定位句所在页
      "words": [412, 418],      // 在 words.json 该页 w[] 里的起止序号（含），卷面高亮用
      "line": { "segment": "conv1", "index": 7 }   // 听力：逐字稿行号（C 轮之后）
    },
    "reasoning": "两三句话，题干问什么 → 原文说什么 → 所以选什么",
    "options": { "A": "原文未提及", "B": "偷换概念：原文说的是……", "D": "与原文相反" },
    "mapping": [{ "stem": "view … as a chance", "text": "place more value on" }],  // 长篇阅读
    "grammar": "空格前是 be，应填过去分词或形容词",                                // 选词、完形
    "meaning": "句意是……，rewarded 符合",
    "vocab": [{ "w": "expectation", "zh": "期望" }],
    "translation": "定位句的中文",
    "points": ["……"], "phrases": [{ "en": "…", "zh": "…" }]                        // 写作、翻译
  },
  "fieldsBy": "ai",
  "fieldsVersion": 1
}
```

- `words` 由脚本把 `quote` 在 `public/papers/pdf/<id>.words.json` 里模糊匹配得到（去空格按前 7 个字母比，允许 15% 不匹配，应对 OCR 错字）；匹配不到就只留 `where`/`quote`，界面不显示"在卷面上标出"
- `line` 由脚本在对齐好的 `audio.segments[].lines[].text` 里匹配
- `polish_explanations.py` 要改成**保留任何条目的 `fields`**（现在官方条目每次重建会丢字段）

## 3. 生成流程

`scripts/structure_explanations.py`（新）：

1. 对每道选择题拼输入：这道题所在部分的原文（`words.json` 里该部分页面的文字，按阅读顺序拼句）、题号、选项字母、答案键、现有解析文本（官方或 AI）、题型
2. 让模型输出上面的 `fields` JSON（固定 schema，温度低）。要求：`reasoning` ≤ 120 字；`options` 只写错误项、每项 ≤ 30 字；`quote` 必须是原文里连续的一句（≤ 25 词）；`vocab` 3–5 个、必须出现在原文；修掉现有文本的 OCR 错字；中文解析，英文引文保留
3. 校验后才写回：`answer` 必须等于答案键；`quote` 能在 `words.json` 里匹配到才填 `words`；`options` 的键必须是该题选项集合减去答案；`vocab` 的词在原文里；任何一项不过就重试一次，再不过标 `fieldsFlag`
4. 分批、可断点续跑（按试卷），每套写完就保存；最后输出覆盖率表
5. 翻译、写作：输入参考范文 + 题目，输出 `points`、`phrases`

由子代理跑（59 套约 2400 题），**在 C 轮子代理完成之后**（它在跑 `polish:explain`，会和这里改同一批文件）。

另外：`scripts/answer_audit.py` 顺便核对 `fields.answer`；`docs/试卷数据格式.md` 解析层一节补上 `fields`。

## 4. 界面实现（并入 B 轮）

- `src/exam/Explanation.tsx` 改成按 `fields` 渲染的 `ExplanationCard`（没有 `fields` 时退回现在的 `text` 渲染）
- `ExamRoom.tsx` 提供 `flashWords(page, [from, to])`（临时高亮并滚过去）和 `playLine(segment, index)`；通过 props 传给 `SidePanel`
- `SidePanel.tsx` 的解析面板：默认"错题和未答"，一题一张纸，逐项和生词折叠；"+ 生词本"调现有 `addToVocab`
- `src/lib/papers.ts` 的 `applyExplain` 把 `fields` 挂到 `question.explain`（类型 `ExplainFields`）

## 5. 验收

- 任意一套四级卷：错题的解析四段齐全（定位、思路、逐项、生词）；随机抽 10 道阅读题，"在卷面上标出"至少 8 道能标到正确的句子；听力错题能播放定位句
- 抽 30 条解析读一遍：没有明显 OCR 错字，没有和答案键矛盾的
- 解析面板一屏能看完 3 道题的"定位 + 思路"
