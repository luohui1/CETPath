# 设计任务：F 轮——平板上实测出的问题（触控、查词、高亮、布局）

> 2026-11-03。用户第一次在 iPad 上用了做题页，反馈如下（原话压缩）。**这些比 D/E 轮剩下的功能优先**：它们挡住了真实使用。
> 做题页文件：`src/exam/ExamRoom.tsx`（工具栏、页面布局、缩放 `scale`）、`src/exam/PaperPages.tsx`（`ExamPage`、`WordLayer` 点词层、`QuestionMarker`、`ChoicePanel`）、`src/exam/InkLayer.tsx`（手写、高亮、下划线、便签；笔/手指判断在 226–240 行附近）、`src/components/WordPopover.tsx`（查词卡）、`src/lib/marks.ts`（`wordAt`、`wordRange`、`strokePath`）。单词坐标 `public/papers/pdf/<id>.words.json`。视口 meta 没有禁用缩放（`index.html` 第 6 行）。

## 1. 双指不能缩放试卷

- 现象：在卷面上双指捏合没有反应。
- 原因：`InkLayer` 为了手写把指针事件吃掉了（`touch-action: none` 或 pointer capture），浏览器的捏合到不了页面；应用自己也没处理双指。
- 做法：在卷面容器（`ExamRoom` 的 stage）自己实现捏合：同时按下两个 `touch` 指针时进入缩放态，按两指距离比例改 `scale`（范围 50%–300%），以两指中点为锚点同步调整 `scrollLeft/scrollTop`，松开后才触发重绘（现有的 `renderScale` 220ms 防抖就够）；缩放态下不画任何笔迹，手指抬起后恢复。工具栏的 ± 和 100% 保留。
- 验收：iPad 上任何工具下双指都能缩放，缩放中不出现笔迹，缩放后点词位置仍然准。

## 2. 手指点单词看不到释义；查词卡遮住单词；卡片太满；笔模式下双击查词

- 现象：手指点单词"完全没有"反应；用鼠标/笔点出来的卡片盖在单词上；卡片内容太多。
- 原因：`InkLayer` 把 `touch` 当平移/手掌，手指的 tap 没有转发给 `WordLayer`；`WordPopover` 定位只按鼠标习惯算。
- 做法：
  1. **手指 tap = 查词**（任何工具下）：手指按下后 300ms 内抬起且位移 < 8px → 用 `wordAt(page, x, y)` 找到词，走和鼠标一样的 `onWord`；位移超过就是平移/滚动。
  2. **笔模式下，笔双击 = 查词**：`pointerType === "pen"` 在 350ms 内在同一位置（< 10px）两次按下 → 不画第二笔，撤销第一笔那个点（如果已经落下），弹查词。
  3. **卡片不遮词**：优先放在单词**下方**，下方不够就放上方，左右贴边不出视口；卡片上有一个小三角指向单词；弹出时卷面不滚动。平板浮动面板打开时卡片层级在面板之上。
  4. **卡片只显示释义**：单词、音标、发音按钮、释义（最多 4 条词性行）、"+ 生词本"。考试标签、真题例句、更多释义折到一个"更多"里，默认不显示。按密度规则，不要说明小字。
- 验收：iPad 上手指点一个词 → 卡片出现在词下方，不遮词；再点别处关闭；笔模式下笔双击同样能查；卡片一屏内读完。

## 3. 题目旁边要能点选答案、直接看解析

- 现象：用户在平板上找不到"点题号选答案"的地方；也想直接看这道题的解析。
- 原因：`QuestionMarker` 在触屏上太小或被 `InkLayer` 压住，手指点不到；解析只有交卷后在面板里。
- 做法：
  1. 题号标记在触屏上至少 40×40 的热区，层级在墨迹层之上（笔在画的时候可以临时让位），手指和笔都能点开 `ChoicePanel`。
  2. `ChoicePanel` 里加一个"解析"按钮（`普通做题`、专项、练习、重做都显示；**全真模拟交卷前不显示**），点开在选项框下方展开这道题的 `ExplanationCard`（和面板里同一个组件），再点收起。
  3. 完形的空位标记同样处理。
- 验收：手指点题号 → 选项框 → 选字母 → 框里有"解析"可展开；全真模拟下没有。

## 4. 高亮"太差、太乱、只盖住一部分词"

- 现象：划过去的高亮断断续续、只覆盖部分单词，看起来乱。
- 原因：现在是按笔迹的包围盒取 `wordRange`，斜着划、抖一下就取错；预览和最终结果不一致。
- 做法（做成"按词吸附"的荧光笔）：
  1. 落笔点所在的词是起点；移动时取当前点所在的词为终点；高亮 = 阅读顺序上起点到终点之间的**所有整词**（同一行是连续一段；跨行时上一行到行尾、下一行从行首）。当前点不在任何词上时，用离当前点最近的那一行里最近的词。
  2. 实时预览就是最终样子：每一行一个圆角矩形（合并同行连续的词），`mix-blend-mode: multiply`，颜色按当前荧光笔色；抬笔后直接写进 `marks`，不重新计算。
  3. 单击一个已有高亮 = 选中（显示删除）；再划一次同一段 = 取消。
  4. 下划线同理按词吸附，画在词的基线下 2px。
- 验收：在 iPad 上手指或笔随便斜着划过三行，得到三条整齐的整词高亮；没有半个词；预览到最终不跳。

## 5. 手写写完会闪一下

- 现象：抬笔瞬间笔迹消失又出现。
- 原因：画的时候在临时层，抬笔后写入 `marks` 表、等 `useLiveQuery` 返回再画正式层，中间有一帧没有这条笔迹。
- 做法：抬笔后把这条笔迹留在本地状态（乐观显示），等数据库里的同一条（按 id）渲染出来后再从本地状态移除；或者正式层直接从"本地待提交 + 数据库"的合并列表渲染。撤销/重做要和本地状态一致。
- 验收：连续快写 20 笔，没有任何一笔闪烁。

## 6. 平板横屏布局：上面遮挡太多

- 现象：1180×820 横屏时，顶栏 + 工具栏占了两行，卷面只剩一半高。
- 做法：
  1. 高度 < 900px 的横屏：顶栏和工具栏**合并成一行**（左：返回 + 卷名小字；中：工具；右：计时/秒表、面板按钮、交卷），高 48px。
  2. 卷面滚动时自动隐藏这一行（向下滚隐藏、向上滚或点卷面顶部露出），状态条也隐藏；听力条打开时固定在底部不遮卷面（卷面底部留出它的高度）。
  3. 浮动面板（答题卡/解析）在横屏下从右侧滑入、宽 360，不盖住卷面中线左侧。
- 验收：1180×820 下卷面可见高度 ≥ 700px；820×1180 竖屏保持现状。
