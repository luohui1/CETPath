# I 轮补充：逐句原文的规范（2026-11-09）

> 用户看了 I 轮上线后的停靠区"原文"标签："逐句精听的文案乱完了""做好逐句原文的规范啊，就是把角色、问题、正文、不同篇分开，然后答案高亮标记"。
> 本任务书接在 `设计任务-I轮-听力与译文与小窗.md` 后面，§0 的句子键、译文层、"只在判过的题上显示答案"等规则照旧。

## 1. 界面：原文标签怎么排（界面线，只动 `src/`）

一个原则：**一眼分得清"哪篇、谁在说、哪句是题、哪句是答案"**，其他都往后放。

### 1.1 篇

- 每段录音（`segment`）是一块。块头一行：左边段名（`Conversation One`、`Passage Two`、`Recording Three`、`News Report One`，用数据里的 `label`），右边题号范围"第 8–11 题"（用题组的题号，和时间轴下面的范围一致）。块头 14px、墨色、加粗，下面一条细线。
- 块头在列表里 `position: sticky` 贴顶：滚到哪篇，顶上就是哪篇；正在播的那篇块头左边一个 3px 蓝色竖条。
- 块与块之间留 20px。不加"Section A/B/C"标题（每套考卷的分法不一样，块头已经够分）。
- 题组提示句（`cue`，"Questions 8 to 11 are based on…"）不再作为一行显示，块头已经写了题号范围。指导语（`directions`）照旧不显示。

### 1.2 正文

- **对话**（这一段有说话人数据）：连续同一个人的几句合成一"轮"。每轮开头一个角色章：`M`（实心墨色小方章，白字）、`W`（空心墨色描边小方章，墨字），18×18，圆角 4px，和第一行文字基线对齐。同一轮里后面的句子不再出章，但和章右边的文字对齐。轮与轮之间留 10px，同一轮里句与句之间 2px。
- 每一句照旧是单独的一行：点了从这句播，正在播的那句整行淡蓝底和进度。
- **短文、新闻、讲座**，以及没有说话人数据的对话：不要左边那一栏（现在是空着的 20px），句子直接顶格，句与句之间 4px。
- 文字里如果还带着 `M:`、`W:`、`Man:`、`Woman:` 前缀（有说话人字段时），显示时去掉，免得和角色章重复。

### 1.3 问题

- 正文后面是这一篇的读题行，前面一个 13px 灰字小标题"问题"。
- 每道题一行：衬线体题号"8."（和卷面上的题号同一种字），后面是题干（去掉 `Question 8.` 前缀，现在已经在去）。整组题放在一块浅灰底（`--fill-quiet`）、10px 圆角的卡片里，和正文明显分开。
- 点一道题的行：照旧从这句播。
- **判过之后**（交卷后、练习模式这道题答过、错题本进来的那道，规则同 I 轮 §2），题干右边：正确答案一个蓝色小圆（字母）；答错的再跟一个红色、划掉的"你的选项"；没答写灰字"没答"。题号前面加一个"答案句"小按钮（↑ 图标即可），点了列表滚到这道题的答案句并让它闪一下。
- 判之前只显示题号和题干，不显示任何答案信息。
- 这道题数据里没有读题行时，不补假的行，问题卡片里只列有的。

### 1.4 答案高亮

- 判过之后，答案句用**荧光笔**标：文字后面一层黄色（视觉方向里"黄色只用来标记"那支荧光笔，用 `src/theme.css` 里的 `--mark` / `--mark-tint`，和卷面高亮同一支笔），只盖文字下半部分或整行文字底，不铺满整行；左边保留现在的蓝色题号标签（点了在卷面上打开这道题）。去掉现在的淡蓝下划线。
- 正在播的那句是整行淡蓝底，答案句是文字后面的黄，两者同时出现时都要看得出来（截图验证）。
- 一句对应几道题时，题号标签并排（"3""4"）。
- 判之前不标，和 I 轮一致。

### 1.5 译文和"译"

- 每行右边的"译"改成**只在当前这句（正在播的、或刚点过的那句）右边出现**，其他行不占这一栏，列表整齐。顶上的"译文"总开关不变。
- 打开整篇译文时，每句中文跟在这句英文下面，和英文左对齐（对话里也在角色章右边对齐）。

### 1.6 交卷前（原文遮着）

- 块头照常显示（段名、题号范围）。
- 对话里的角色章照常显示（不泄题，还能帮着跟上谁在说），句子是灰色条。
- 问题卡片里只显示"8." 和灰色条。

### 1.7 验收

- 三种尺寸（1180×820、820×1180、1024×768）各截：
  1. cet4-2025-12-1 交卷后：新闻篇 + 对话篇（有角色章）+ 问题卡片（有对有错有没答）+ 答案句荧光笔；
  2. cet6-2024-12-1 交卷后：讲座篇（Recording）+ 问题卡片 + 正在播的句子刚好是答案句；
  3. 任一卷交卷前：块头、角色章、灰色条；
  4. 一段没有说话人数据的对话（数据线修之前找一段，例如对话段里 `speaker` 全空的）；
  5. 打开整篇译文的对话段。
- 量：块头贴顶时不盖住正在播的那句（播放自动滚动把当前句放在块头下面）；侧栏 360px 下题号范围不折行。
- 自查：点题行从这句播、点"答案句"能滚过去、点题号标签能在卷面打开题；交卷前列表里没有任何答案字母。
- `tsc`、`npm run build` 通过。**先不发布**，测完告诉规划会话，由用户决定发布。

## 2. 数据：把原文洗干净（数据线，只动 `scripts/`、试卷 JSON 的 `audio`、`explain/`、`trans/`）

先写检查脚本，再修，修完用同一个脚本出前后数字。

### 2.1 检查脚本 `scripts/transcript_lint.py`

按录音去重（第 3 套共用的只算一次），输出每段的问题，至少包括：

- 读题行：形如 `Q20;`、`Q1o:`、`20:`、`1.`、`Question 7.` 开头且以问号结尾、不在 `question` 里的；每段题组里的题号有没有都有读题行。
- 题组提示没标 `cue` 的。
- 对话段说话人覆盖率；一行里夹着第二个 `M:`/`W:` 的。
- 噪声：不在词典（`public/dict/` 的词 + 词形表；注意 `wouldn't` 这类缩写要整体认，别拆成 `wouldn`+`t`）的词占比；≥ 14 个字母且不在词典的长串（粘连）；`²³{}[]|` 这类符号、罗马数字段落标记、句首多出来的 `I`/`V`；汉字；`A)`–`D)` 开头的选项行。
- 时间：每句"词数 / 时长"异常（> 7 词/秒，或 > 3 秒且 < 0.6 词/秒）；整段"词数和时长"的相关系数 < 0.6 的段。
- 输出 `data/cache/transcript-lint.json` 和一行汇总。

### 2.2 修（按便宜到贵的顺序）

1. **标记**：没标的读题行标 `kind: "question"`，文字统一成 `Question N. 题干`（题号按这一段题组的题号顺序校正：`Q1o` → 10、`Q20;` → 20）；没标的题组提示标 `cue`。
2. **拆行**：一行里夹着两个人的话，按 `M:`/`W:` 拆成两句，时间按词数比例分，说话人填上。
3. **去符号**：删掉杂符号、罗马数字段落标记、句首多出来的单个 `I`/`V`（后面紧跟大写单词时）；选项行整行删掉。
4. **拆粘连**：不在词典的长串，用词典做最短切分（只在能完全切成词典词时才切，切不开的不动），例如 `doyou` → `do you`、`Whenfaced` → `When faced`。只改空格，不改字母。
5. **补说话人**：28 段说话人没标全的对话，先从解析书原文的 `M:`/`W:`/`Man:`/`Woman:` 按句对齐填；书里也没有的，留空，列出来（界面在没有说话人时不出角色章，不会出错）。
6. **重识别**：上面几步之后，噪声比例仍高的段（例如 lint 里乱词 ≥ 3 句的段）和时间错位的段（至少 cet6-2020-09-1/2 的 rec1–rec3、conv2），用现成的 `asr_listening.py` 重识别、解析书校对后写回，`"source": "asr"`。照旧一次一个识别进程，排在手上的识别任务后面；先报一下要重识别多少段、预计多久。
7. **跟着改的**：原文改了的句子，`locate.line` 用 `listen_locate.py` 重新对一遍（行号可能变）；句子键变了的，`build_trans.py todo` 会列出来，跟下一批译文一起译（2023–2026 年已经译过的听力句，改了文字的要重译）。

### 2.3 验收

- lint 前后对比表（每一类问题的数量）。
- 抽查：每类修法各抽 10 句贴原句和改后的句子，重识别的段每段抽 3 句对录音（用识别缓存的逐词时间）。
- `check:papers`、`answer_audit`、`npm run build` 通过。写进 `I轮-数据-实施报告.md`。
