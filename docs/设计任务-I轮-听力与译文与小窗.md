# 设计任务：I 轮——听力缺段、答案位置、全局句子译文、小窗不重叠

> 2026-11-09。用户在 iPad 上用了 H 轮之后的线上版，提了五件事（原话压缩）：
> 1. "有一部分听力里面有几段是缺失的"。
> 2. "能不能为听力标记一下答案的位置"。
> 3. "能不能加入全局句子翻译功能"；"听力能不能也有句子翻译"。
> 4. "很多小窗存在重叠问题，比如我打开听力逐句精听，其他小窗就会被盖住。逐句精听能不能做成可以拖动的，或者放在侧边"。
> 5. "你看看全局怎么优化交互展示"。
>
> 分两条线做，**两边改的文件不重叠**：
> - **数据线**（§1 §2 §3 的数据部分）：只动 `scripts/`、`public/papers/*.json` 的 `audio` 字段、`public/papers/explain/`、新目录 `public/papers/trans/`。
> - **界面线**（§2 §3 的界面部分、§4、§5）：只动 `src/`、`vite.config.ts`。
> 两边约定的数据格式在 §0，照它写、照它读；数据没补齐之前界面要能正常降级。

## 0. 两边约定的数据格式

### 0.1 句子的键

卷面句子来自 `public/papers/pdf/<id>.words.json` 的 `pages[].s`（考场点词时 `WordClick.sentence` 就是这里的一句），听力句子来自试卷 JSON 的 `audio.segments[].lines[].text`。两边用同一个函数算键：

```
norm = text.normalize("NFKC").toLowerCase().replace(/[^a-z0-9]+/g, " ").trim()
key  = FNV-1a 32 位（norm 的字节，此时只有 ASCII），8 位小写十六进制
```

TypeScript 放 `src/lib/trans.ts`，Python 放 `scripts/trans_key.py`，各写一个单测：`"Hello,  World!"` → norm `hello world`，两边算出同一个键。

### 0.2 译文层 `public/papers/trans/<id>.json`

```jsonc
{
  "id": "cet4-2025-12-1",
  "by": "ai",                 // 全部是 AI 译文，界面上标"AI 译文"
  "version": 1,
  "sentences": { "3f9a2c1e": "不到一个月后，特奥会春季运动会将重返费耶特维尔。", "...": "..." }
}
```

- 少于 4 个英文词的句子不收（标题、题号、"Questions 1 and 2 are based on…"这类指导语也不收）。
- 文件不存在、或某句没有键，界面显示"这句还没有译文"，不报错。
- Service Worker 缓存规则和 `papers/explain/` 一样（StaleWhileRevalidate）。

### 0.3 听力答案位置

沿用解析层已有的字段：`public/papers/explain/<id>.json` → `questions[qid].fields.locate.line = { segment, index }`，`index` 是该段 `lines` 数组里的下标。界面只读这个字段。

## 1. 听力缺段（数据线）

现状（2026-11-09 统计目录里 136 套四六级）：

| 问题 | 范围 |
| --- | --- |
| 整段录音没切成题组，卷面上没有逐组播放按钮 | cet6-2016-12-2、cet6-2016-12-3、cet6-2026-06-1、cet6-2026-06-3 |
| 分段在，但没有原文（逐句精听里这一段是空的） | 约 17 套共 61 段，集中在 2015–2022 年六级（2021-12、2022-06 三套各缺 5–6 段）和四级 2015-06、2015-12、2018-12、2019-12 |
| 原文只有一两句 | cet4-2018-12-1/3 的 pass1、cet6-2018-06-2/3 的 rec2、cet4-2026-06-1 的 pass2 |

注意："原文只盖住 45–50%"不是问题，新闻和对话段后半是读题和停顿。

做法：
1. 四套整段的：按"Questions X to Y are based on…"切段（先试 `ffmpeg silencedetect` + 段落结构；切不准就用下面第 2 条的本地识别找这些提示句的时间）。切完 `audio.segments` 和每个题组的 `audioSegment` 都要有。
2. 没原文的段：先改进 `scripts/align_transcripts.py` 从解析书里取原文（已知难点：原文和带中文的选项混排，2026-11-04 曾经把选项当成了原文，已撤回——**这次每段原文都要人工抽查，不能再出现选项当原文**）；书里确实没有原文的段，用**本地**语音识别（faster-whisper，small 或 medium、int8、CPU，一次只跑一个进程，不上传录音）出原文和时间戳。识别出的原文在试卷 JSON 里标 `"source": "asr"`，界面不用区分。
3. 只改 `audio` 字段，题目、答案、解析、卷面定位不动；改完 `npm run check:papers`。

## 2. 听力答案位置

### 数据线：补齐 `locate.line`

现状（3400 道听力题）：已有行号 1456；只有引文、段里有原文 724；没定位、段里有原文 906；段里没原文 314。

1. 只有引文的 724 道：在本段原文里模糊匹配引文（词重合度最高、且 ≥ 0.6 的那一句或连续两句），写 `line`。
2. 没定位的 906 道：用 AI 读本段原文 + 题干选项 + 答案，挑出答案依据那一句，**必须原样出现在原文里**，写 `line` 和 `quote`；脚本校验不通过的不写。
3. §1 补出原文的段，同样做 1、2。
4. 每批跑 `answer_audit.py` 和解析校验；报告写覆盖率前后数字。

### 界面线：在原文和时间轴上标出来

- **只在判过的题上显示**（交卷后；练习模式这道题答过之后；错题本里），做题中不显示，免得漏答案。
- 原文面板（§4 的"原文"）：答案句左边一个小号蓝色题号标签 `3`，这句文字下面一条淡蓝底线；点题号标签 → 卷面打开这道题（选项条 + 解析），点句子照旧从这句播放。
- 听力条时间轴：判过的题在答案句的时间点上画一个小刻度（2px 宽、6px 高、蓝色），悬停/按住显示"第 3 题"。
- 解析卡里已有"听这一句"，不变。

## 3. 全局句子译文

### 数据线：生成译文层

- 句子范围：目录里所有试卷的卷面句子（`words.json` 的 `s`）+ 听力原文句子，去重后约 3.3 万 + 1.3 万句（§1 补出的原文另算）。
- 用 AI 子代理批量翻译，忠实、通顺、不加解释；专有名词保留英文或通行译名。**同时最多 3 个子代理**。
- 先试点 `cet4-2025-12-1` 一套，抽 30 句人工看质量，再按年份从新到旧分批：2026–2024、2023–2022、2021–2019、2018–2015；每批写完就能用，用户随时可能叫停。
- 每批报告：句数、token 用量、抽查结果。
- 写一个 `scripts/build_trans.py`：列出某套还缺哪些句、合并子代理结果、校验（键能对上、译文非空、不是英文原样），可以反复跑。

### 界面线：在哪儿看译文

1. **卷面点词**：底部查词条上加一个"译句"按钮（和"更多"并排）。点了展开抽屉：上面这句英文原文（衬线，点到的词加粗），下面中文译文（灰一点），右上角"AI 译文"小章。不做新的弹窗。
2. **长按一句**（手指按住 500ms 不动；鼠标右键）：直接出这句的译文（同上抽屉），卷面上这句整句用很淡的黄底标出，收起抽屉时去掉。
3. **听力原文**（§4 的"原文"）：顶部一个开关"译文"，打开后每句英文下面跟一行中文；每句右边也能单独点"译"只看这一句。交卷前原文是遮住的（现状），译文同样遮住。
4. 没有译文的句子：抽屉里写"这句还没有译文"。

## 4. 小窗不重叠：一个侧栏装下所有面板

现状：逐句精听是浮在卷面上的大面板（`ListeningBar.tsx` 第 434 行，`absolute bottom-[calc(100%+8px)]`），答题卡面板（`SidePanel`）又是另一块浮层，两个一开就互相盖住；竖屏时逐句精听把卷面挡掉一大半。截图见会话笔记目录 `I轮/现状-*.png`（1180×820、820×1180）。

规则：**所有"面板"都放进同一个停靠区，同一时间只开一个标签**；浮在卷面上的只允许选项条、小菜单这类一点就走的东西。

- **横屏、或宽度 ≥ 1100**：右侧停靠栏，宽 360，**把卷面挤窄**而不是盖在上面（卷面按新宽度重排，当前看的那一页保持在原位）。
- **竖屏、宽度 < 1100**：底部抽屉（在听力条上面），顶部一个拖拽把手，三个停留高度：40%、70%、92%；拖到底就收起。卷面底部让出抽屉的高度，被点的题、正在听的那句照旧自动让到可见区域。
- 停靠区的标签：`答题卡` `原文`（有录音的卷才有）`解析`（能看解析时才有）`笔记` `生词`，写作翻译题打开时多一个 `作答`。记住上次开的标签。
- 听力条上的"逐句精听"按钮改名"原文"，点了打开停靠区的"原文"标签；再点收起。原来的浮层删掉。
- 原文标签的内容就是现在逐句精听的内容（按段列句子、点句子播放、单句重复、逐句暂停），再加 §2 的答案标签、§3 的译文开关。正在播的那句自动滚到中间。
- **竖屏时只有一块底部区域**：底部抽屉开着时，查词和解析不再另起底部条，而是作为抽屉里临时出现的标签（"查词"/"解析"）；抽屉关着时照旧用底部条。横屏时底部条只占卷面那一栏，不伸到侧栏下面。
- 层级只分三层：卷面 → 停靠区和底部条（并排，不互相盖）→ 一点就走的小菜单。Esc / 点卷面空白只关最上面一层。

## 5. 全局交互顺手要做的

1. 状态栏那句"点题号旁边的圆圈选答案 · 点单词查词"只在一道都没答时显示（现在一直在）。
2. 听力条在竖屏是两行（时间轴一行、按钮一行），停靠区底部抽屉要在它上面，不能把它挤没。
3. 停靠区开关、标签切换不能让卷面滚动位置跳。
4. 按密度规则（`docs/设计任务-A轮-现代化.md` 第 11 节）过一遍：不加说明小字，每个面板一个标题。
