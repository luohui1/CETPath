# 设计任务：A 轮——把「考场与文具」做得现代、有分量

> 写给实施者的任务书。2026-11-03。背景见 `优化路线.md` 第 2 节；令牌在 `src/theme.css`，小件在 `src/components/paper-ui.tsx`。

## 0. 为什么要做这一轮

上一版把方向定成「考场与文具」（纸色桌面、白纸卡片、墨字、红笔批改、衬线数字、答题卡小泡、原卷缩略图、红章）。用户的反馈：**方向对了（"好了一点"），但是**

1. **太简单**：一页全是一样大小的白卡片、小号灰字、细线条，没有主次，没有厚度，空得像线框图。
2. **图标太 AI**：lucide 这种一笔画的线性图标是所有 AI 生成界面的默认模样，一眼就看出来；和"试卷"也没关系。
3. **要现代化**：参考 2025–2026 年高端产品的做法——有层次的阴影和材质、便当盒式的版面（bento，卡片大小不一、信息密度有节奏）、大字号的数字和标题、双色图标、克制但到位的动效。

这一轮**不换方向**，只把它做足：纸要像纸，章要像章，图标要像文具，版面要有编辑感。

## 1. 验收标准

做完后在 1366×1024、1180×820、820×1180 三个宽度截图，对照下面每条：

- [ ] 整套应用里**没有一个 lucide 图标**、没有表情符号、没有像素风、没有多邻国式立体按钮和糖果色
- [ ] 5 个主导航 + 8 种题型用的是**我们自己画的双色文具图标**（见第 3 节）；其余界面图标统一用 Phosphor duotone
- [ ] 首页是 bento 版面：倒计时牌是主角（跨两列），其余卡片大小有区分，一屏内能看到"今天做什么"
- [ ] 卡片有三级层次（桌面上的纸、抬起的纸、浮起的面板），阴影是多层柔和的，不是一圈灰线
- [ ] 数字和英文标题用自带的衬线字体（第 6 节），中文用系统无衬线；字号有明确的梯度
- [ ] 做题页的答题卡看起来像一张机读答题卡
- [ ] 平板竖屏不出现横向滚动、不出现叠成一列的小泡、按钮触控区 ≥ 40px
- [ ] `npm run build` 通过；切页仍然在 100ms 内（已有缓存机制，别破坏）

## 2. 风格基调：高级文具店，不是儿童乐园

- **材质**：纸有纹理（极淡的噪点），卡片边缘有细微的高光和多层阴影，像真的一张纸放在桌上；重要的纸（倒计时牌、当前卷子）更"厚"。
- **颜色**：还是纸、墨、品牌蓝、红笔、荧光黄五种。现代感来自**明度层次**（纸-50/100/200 三级底色、墨-900/700/500 三级文字），不是来自更多颜色。
- **形**：圆角 10–14px；大面积用直角感的纸张，小件（标签、泡、章）用小圆角。
- **字**：标题大而轻（28–40px，weight 600），正文 14px，辅助 12–13px；数字一律衬线、正体、等宽。
- **留白**：卡片内边距 20–24px，卡片间距 16–20px；一屏里要有一处"重"（倒计时牌或当前卷子）、几处"轻"。
- **参考感觉**（只学气质，不抄界面）：Things 3 的层次与留白、Craft 的纸感、Linear 的字号梯度与阴影、Apple Freeform 的材质、墨墨/不背单词的高级克制。

## 3. 图标系统（这一轮的重点）

### 3.1 两层图标

| 层 | 用途 | 来源 | 风格 |
| --- | --- | --- | --- |
| 品牌图标（13 个） | 主导航 5 个、题型 8 个——出现在首页、真题、专项、答题卡、解析里，承载"文具"身份 | **自己画**，`src/components/icons/` 下每个一个 React 组件，24×24 viewBox | 双色：墨色描边（1.75px，圆头圆角）+ 一块实色填充（品牌蓝 `--blue-tint` 或红 `--red-tint` 的实色，按语义选），填充块略微错位，像印刷套色没对齐 0.5px 的感觉 |

### 3.3 文具装饰元素（SVG，放在 `paper-ui.tsx`）

不是图标，是让纸"像纸"的小东西，每种只在该出现的地方出现一次：

- **回形针** `Clip`：挂在"接着做题"卡片左上角，压住缩略图
- **便签纸** `StickyTab`：年份分组的标题做成从卡片左边伸出的彩色小标签（纸-200 底，墨字），像档案夹上的索引
- **印章** `Stamp`：已有，加一层极淡的噪点蒙版和 2% 的随机旋转（-8°～-4°），每次渲染固定（按 id 哈希），看起来像真盖上去的
- **荧光笔划痕** `Highlight`：标题关键词背后一道荧光黄、两端不齐的色块（`::before` 伪元素 + `skew`），首页标题和弱项题型用
- **装订孔** `Punch`：答题卡顶部一排 3 个灰圆（像真的答题卡），只在答题卡面板用
- **纸纹** 全局：`body::before` 盖一层 SVG `feTurbulence` 噪点（`baseFrequency 0.8`，`opacity 0.035`，`mix-blend-mode: multiply`），`pointer-events: none`，`position: fixed`

## 4. 版面

### 4.1 首页：bento

12 列网格，`xl` 以上 3 列，平板横屏 2 列，竖屏 1 列。卡片按下面的顺序和跨度放：

| 卡片 | 跨度 | 内容 |
| --- | --- | --- |
| **倒计时牌**（主角） | 2 列 | 现有内容，但红数字放到 96–112px，右侧一枚大红章"冲刺阶段"；底部三个数字横排；牌子比其他卡"厚"一级 |
| **今天** | 1 列（高） | 新增：今天的三件事——待复习 N 词（来自 `pendingCounts`）、建议一篇 X（最弱题型，来自 `useKindStats`）、本周还差 N 套整卷（按"每周两套"算）。每件事一行：双色图标 + 文字 + 右侧一个小按钮。都做完就显示一枚红章"今日已完成" |
| **接着做题** | 2 列 | 现有内容，缩略图改成**三页错开的扇形**（第一页清晰，后两页只露边，用 `PaperThumb` 三次 + 旋转 -4°/0°/4°），左上角夹一个回形针 |

### 4.5 做题页

- **答题卡面板**：（2026-11-03 改）用户要**简单**：一张纸，顶部已答 N/M + 筛选，下面按部分分组的**题号网格**（36px 格子、圆角 6px、只显示题号，状态靠底色：未答白、已答浅蓝、交卷后对浅蓝/错浅红/未答灰、标记是右上角一个小点）。不做装订孔、不做 ABCD 泡行、不加进度条和说明文字。详见 `设计任务-B轮-练习闭环.md` B0.4

- **听力条**：保持功能，图标换掉；时间轴刻度上的题号用衬线小字
- **解析面板**：【定位】【详解】小标签用纸-200 底 + 墨字（不再是蓝底）；AI 解析的标记用一枚小蓝章
- **交卷对话框**：做成一张"交卷单"（纸张 + 顶部红线 + 衬线大数字）

## 5. 层次与材质（写进 `theme.css`）

```css
:root {
  --paper-50: #faf8f3;  /* 最浅：卡片内的分区底 */
  --paper-100: #f5f2eb; /* 桌面 */
  --paper-200: #ebe7dd; /* 便签、标签底 */
  --ink-900: #1c2330; --ink-700: #3d4654; --ink-500: #6b7482; --ink-300: #a9b0ba;
  /* 三级阴影：桌上的纸 / 抬起的纸 / 浮起的面板 */
  --elev-1: 0 0 0 1px rgba(28,35,48,.06), 0 1px 1px rgba(28,35,48,.04), 0 2px 6px -2px rgba(28,35,48,.08);
  --elev-2: 0 0 0 1px rgba(28,35,48,.08), 0 2px 4px rgba(28,35,48,.05), 0 12px 24px -12px rgba(28,35,48,.22);
  --elev-3: 0 0 0 1px rgba(28,35,48,.08), 0 8px 16px -6px rgba(28,35,48,.16), 0 28px 48px -20px rgba(28,35,48,.32);
}
```

- 卡片默认 `--elev-1`，悬停或"当前"用 `--elev-2`，弹出层用 `--elev-3`
- 卡片顶部一条 1px 的内高光（`inset 0 1px 0 rgba(255,255,255,.8)`）让纸有厚度
- 卡片内分区用 `--paper-50` 底 + 虚线横格（`.rule`），不要再嵌套一层卡片

## 6. 字体

- 中文界面：系统无衬线（已定）
- **数字与英文展示**：自带一款衬线体，替换现在的 Times 回退。用 `@fontsource/source-serif-4`（变量字体，含正体等宽数字，开源），只加载 latin 子集；`--font-serif: "Source Serif 4 Variable", "New York", "Times New Roman", serif`
- 字号梯度（px / 行高 / 字重）：显示 84/0.9/600（倒计时）、40/44/600（页标题的数字）、28/36/600（页标题）、20/28/600（卡片标题）、16/24/500（强调正文）、14/22/400（正文）、13/20/400（辅助）、12/16/500（标签，字距 +0.06em）、11/16/500（最小）
- 衬线数字一律 `font-variant-numeric: lining-nums tabular-nums`

## 7. 动效（都要尊重 `prefers-reduced-motion`）

- 切页：保持 `page-in`
- 卡片悬停：抬起 1px + 阴影升一级，120ms
- **盖章**：交卷、打卡达成时，红章从 1.6 倍缩到 1 倍并轻微过冲，160ms，配合 2° 旋转——像真的盖下去
- **小泡涂黑**：答题时该题的泡 120ms 由白到墨
- 倒计时秒数：数字换位时不要翻页动画，只做 80ms 淡入
- 荧光笔划痕：进入视口时从左到右 240ms 画出来（只画一次）

## 11. 密度与噪声（2026-11-03 用户看过半成品后追加，优先级高于前面所有版面细节）

用户的原话："前端噪音太大，信息密度太高了。"另外他已经要求把桌面和纸改回**近白、略冷的灰**（不要米黄）。"现代、有分量"靠的是层次和留白，不是靠把东西堆满。下面每一条都要落实，和前面冲突时以这里为准。

**判断标准**：每个页面只回答一个问题——首页"今天做什么"，真题"做哪套"，专项"练哪种"，做题页"做题"。看一眼就能回答，就对了；回答之外的东西都是噪声。

1. **一张卡片 = 一个标题 + 一个主要数字或主要动作 + 最多一行辅助文字。** 其余信息要么删掉，要么藏到悬停/展开/详情页里。卡片内不再嵌小卡片、小行、小标签。
2. **每屏最多一处红色。** 红只给真正需要注意的东西（倒计时数字、真正的错题数）。正确率低于 60% 但答题不足 5 题的，**不显示百分比**（显示"—"或不显示这一行），更不要标红。现在首页一列 0%、5% 全红，是最大的噪声源。
3. **文具装饰每屏最多一处。** 回形针、荧光笔划痕、红章、便签索引是签名，不是花纹：首页只留倒计时牌的章（或标题里一道荧光笔，二选一）；真题页只留年份便签；专项页不加装饰；做题页只在答题卡上留装订孔。
4. **同一事实只出现一次。** 真题卡片现在有"57 题 · 125 分钟 · 含听力"+ 各部分题量 + 上次做 + 进度泡 + 箭头，减到：标题、一行元信息、一个状态（没做过 / 进行中 N/57 / 已完成 74%）。各部分题量放到悬停或卷子详情里。
5. **答题卡小泡只给"进行中"的东西。** 0/10 不画泡；已完成不画泡；首页"接着做题"卡里六行泡减成一行总进度泡。
6. **字号**：正文 14、辅助 13；**删掉所有 11–12px 的说明文字**（侧边栏和标签除外）。标题下面不再自动跟一行灰色小字；一个页面最多一处小字说明（页标题下那行）。
7. **图标只在替代文字的地方出现**：题型列表里代替题型名可以，筛选胶囊里不要，数字标签前不要，每行都有文字标签的列表里不要。
8. **留白**：卡片内边距 24px，卡片间距 20px；首页第一屏最多 5 张卡；右侧栏最多两张。
9. **首页结构减到**：倒计时牌（主角）、接着做题（含一行"最弱：听力"的提示，不再单独一张正确率卡）、今天（三行以内，不带按钮，整卡可点）、本周（把连续打卡并进来："本周 · 连续 2 天"，四个数字横排，不要迷你折线——折线放统计页）、最近练习（最多 3 行）。各题型正确率卡移到专项训练页顶部。
10. **真题页减到**：考试切换、筛选（纯文字胶囊，不带图标）、年份分组（左侧便签只标年份，月份用一行小标题）、卡片；删掉顶部概况卡（收录/已完成数放进筛选胶囊的计数里）；右侧年份索引只在年份超过 6 个时显示。
11. **专项页减到**：题型卡（图标、名称、已练 N/全部、正确率——只在答题 ≥ 5 题时显示）、列表。
12. **迷你折线、热力图只在统计页。** 首页学习日历保留但降到最后一张卡，格子不要蓝色渐变，用灰-墨两级。
13. **背景**：近白略冷的灰（如 `#f6f7f9`），纸是纯白；方格点去掉或降到几乎看不见；阴影保留三级但第一级更轻。
14. 做完后用这个办法自检：把页面缩小到 50% 截图，如果还能一眼看出"主角"在哪、一屏里只有一两处深色重点，密度就对了；如果缩小后是一片灰色碎块，继续删。
